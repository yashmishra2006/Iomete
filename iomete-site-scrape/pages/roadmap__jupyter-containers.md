# Jupyter Containers

Status

Completed

Release Version

3.10.0

Last Updated

December 1, 2025

#### Overview

Jupyter Containers is a feature within the IOMETE Lakehouse Platform that enables users to deploy and manage JupyterLab instances as containerized workloads in Kubernetes. This solution provides on-demand, scalable data science environments with persistent storage and seamless integration with the broader IOMETE ecosystem.

#### Planned Features

- Creating a JupyterLab based Containers within IOMETE Ecosystem
- Connecting and working in JupyterLab environment
- Install necessary libraries for working seamlessly with IOMETE Compute
- Improving Authentication mechanism
- Authorization on RBAC
- Jupyter Container persistent storage
- Init script for pre-installing additional dependencies
- Scheduling Jupyter notebooks guide
- Seamless integration with s3 filesystem
- ✨ Enable AI Features in JupyterLab

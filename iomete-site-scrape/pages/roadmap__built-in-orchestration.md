# Built-In Orchestration

Status

Backlog

Last Updated

October 13, 2025

### Overview

The Built-In Orchestration feature introduces a native workflow orchestration engine directly within the IOMETE Lakehouse Platform — eliminating the need for external tools such as Airflow or Prefect.
This component provides a unified, visual environment for designing, scheduling, and monitoring data pipelines, ensuring tight integration with IOMETE’s compute, storage, and governance layers.
It simplifies operational management, reduces infrastructure dependencies, and enables teams to build and automate complex data workflows with zero external setup.

### Planned Features

- Visual Workflow Builder: Drag-and-drop interface to design and connect SQL tasks, Spark jobs, ingestion events, and notebook executions.
- Native Scheduling Engine: Define cron-based or event-driven pipeline triggers.
- Job Monitoring Dashboard: Real-time visibility into job status, execution logs, and performance metrics.
- Task Dependencies & Retry Logic: Define dependencies, conditional logic, and automatic retry mechanisms.
- Tight Integration with IOMETE Services: Seamless connection to SQL Editor, Event Gateway, and Jupyter Containers.
- Alerting & Notifications: Built-in Slack/email alerts for job failures or SLA breaches.
- Parameterization & Reusable Components: Define reusable pipeline templates with parameterized inputs.
- Dynamic Task Execution: Enable conditional branching and looping constructs for complex workflows.
- Execution History & Audit Logs: Full traceability of runs for compliance and troubleshooting.
- Integration with Lineage & Monitoring: Automatically map workflows into the Data Lineage graph and AI-Assisted Monitoring system.
- Versioning & Rollback: Maintain historical versions of pipeline definitions with rollback capability.
- AI-Assisted Workflow Design: Suggest optimal pipeline structures, dependencies, and execution strategies based on historical runs.
- Predictive Scheduling: Adjust execution timing dynamically based on resource usage and workload forecasts.

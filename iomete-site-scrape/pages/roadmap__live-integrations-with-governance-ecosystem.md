# Live Integrations with Governance Ecosystem

Status

Backlog

Last Updated

July 1, 2026

### Overview

Live Integrations with Governance Ecosystem enable seamless, real-time interoperability between IOMETE and leading enterprise data governance platforms such as Informatica, BigID, Alation, etc..

This initiative ensures that governance, compliance, and data discovery workflows remain connected and consistent — allowing users to view, search, and act on governance metadata directly inside the IOMETE Lakehouse environment.

With this feature IOMETE becomes an active participant in the governance fabric, synchronizing metadata, lineage, and quality insights in real time.

### Planned Features

- Live Metadata Synchronization: Real-time retrieval of data asset metadata (e.g., owners, classifications, sensitivity levels) from connected governance tools.
- Inline Governance Context in SQL Editor & Workspace: Display key governance info (data classification, usage policies, ownership) directly alongside datasets.
- Integration Connectors for Popular Tools: Out-of-the-box integrations with Informatica, BigID, and Alation using APIs or event streams.
- Domain-Level Scoping: Integrations respect Data Mesh boundaries and domain ownership.
- Bidirectional Metadata Exchange: Allow governance systems to receive lineage, usage, and quality data from IOMETE in real time.
- Plugin Framework for Future Tools: Extensible architecture to support additional governance platforms or in-house systems.

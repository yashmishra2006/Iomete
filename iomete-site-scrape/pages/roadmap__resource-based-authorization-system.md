# Resource Bundles

Status

Completed

Release Version

3.12.0

Last Updated

July 1, 2026

#### Overview

Resource Bundles change how you organize and manage access to IOMETE resources. A bundle is a logical collection that groups related resources — such as compute clusters, storage configurations, and workspaces — under centralized permission management. Instead of managing role-based permissions, admins grant permissions to users and groups at the bundle level. Bundles support flexible ownership (owned by an individual user or a group), with automatic permission inheritance through group hierarchies, and assets can be moved between bundles as needs change.

Conceptually it's similar to a folder-like container for related resources that also acts as the unit of access control.

#### Use cases

- Project / team isolation — Group all resources belonging to a project or team into one bundle and grant that team access in a single step.
- Environment separation — Keep dev, test, and prod resources in distinct bundles with different permission sets.
- Streamlined onboarding/offboarding — Give a new team member access to everything they need by adding them to the relevant bundle; revoke it all by removing them.
- Delegated administration — Let a team lead manage access within their bundle without granting platform-wide admin rights.

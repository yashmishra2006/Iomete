# Feature Flags

From release 4.0.0 forward, feature flags let IOMETE turn a feature on or off at runtime, without a redeploy.

Admins control them from the admin panel under Administration → Feature Flags — see Managing Feature Flags.

## Available flags

- Secrets V2
- LDAP Group Inheritance
- SQL Editor V2

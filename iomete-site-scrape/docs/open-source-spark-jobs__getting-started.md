# IOMETE Spark Jobs Marketplace

The Spark Jobs Marketplace gives you a library of pre-built jobs you can deploy in minutes instead of writing them from scratch. Browse All apps for built-in jobs covering ingestion, compaction, catalog sync, and more. Switch to My apps to publish your own job templates so others in your organization can discover and reuse them.

## Spark Jobs Marketplace

The Marketplace is where you'll find every built-in job IOMETE ships. Open the Job Templates page, then click Marketplace in the top-right corner.

## Available Jobs

Each card below links to a built-in job you can deploy today. Pick the one that matches your workload to see configuration details and examples.

For the latest version of each job, see the Marketplace Jobs release notes.

MySQL Database Replication Job

Move MySQL tables into the IOMETE Lakehouse with a simple, configuration-driven Spark job.

Query Scheduler Job

Schedule SQL queries to run in your data warehouse on a recurring cadence.

Data Compaction Job

Iceberg tables accumulate small files over time and slow down. This job compacts them on a per-table basis to keep performance healthy.

Lakehouse Backup Job

Back up and restore lakehouse files between S3-compatible object stores and HDFS-compatible storage.

Catalog Sync Job

Keep your data in sync with the Data Catalog so metadata stays accurate.

TPC-DS Generator Job

Generate TPC-DS datasets for benchmarking and performance evaluation.

Kafka to IOMETE Lakehouse Data Replication Job

A ready-to-use Spark Streaming job that replicates Kafka topics into the IOMETE Lakehouse through configuration alone.

File Streaming

A ready-to-use Spark Streaming job that replicates data from file sources (a directory, S3 location, and similar) into the IOMETE Lakehouse.
